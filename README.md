# 적정주가 앱

휴대폰 홈 화면에 설치해 쓰는 개인용 적정주가 계산 앱입니다. 매일 아침 GitHub Actions가 시세와 재무를 받아 DCF와 상대가치로 적정가를 다시 계산하고, 저평가 후보를 골라 GitHub Pages에 올립니다. 서버 비용은 들지 않습니다(공개 저장소 기준 무료).

- **발굴**: S&P 500(금융·부동산 제외), 코스피·코스닥 시가총액 상위, 관심 종목을 1차·2차 기준으로 거른 후보와 관찰 종목
- **노트**: Claude 채팅에서 「티커 적정주가」로 정리한 종목. 가정은 그대로 두고 시세·목표주가만 매일 갱신
- **검색**: 감시 중인 모든 종목. 없는 종목은 「추가 요청 보내기」로 바로 추가
- **상세**: 방법별 적정가 범위, 가정 바꿔보기(이 기기에만 저장), DCF 계산 과정, 민감도 표, 함정 점검

투자 권유가 아닙니다. 데이터는 Yahoo Finance(yfinance) 기준이라 늦거나 틀릴 수 있습니다.

## 처음 설정

1. 이 폴더를 **공개(Public)** 저장소로 올립니다. (Claude가 대신 올릴 수도 있습니다)
2. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
3. **Actions** 탭 → 「데이터 갱신」 → **Run workflow** → `full` 체크 → 실행. 처음에는 약 580종목의 재무를 모두 받느라 20~40분 걸립니다.
4. 끝나면 `https://<아이디>.github.io/<저장소>/` 가 앱 주소입니다.
5. 휴대폰 크롬에서 그 주소를 열고 ⋮ → **앱 설치**(또는 홈 화면에 추가). 아이폰은 사파리 공유 버튼 → 홈 화면에 추가.

그다음부터는 평일 밤 22:37 UTC(한국 화~토 아침 7시 37분쯤)에 자동으로 갱신됩니다. GitHub 사정으로 몇십 분 늦어질 수 있습니다.

## 종목 추가

- 앱 검색에서 없는 종목을 치면 나오는 **추가 요청 보내기** → GitHub 이슈 화면에서 그대로 제출. 제목이 `add: LMT` 형식이면 자동으로 `config/watchlist.txt`에 추가하고 바로 계산한 뒤 이슈를 닫습니다.
- 저장소 주인이 연 이슈만 처리합니다(다른 사람이 연 이슈는 무시).
- 직접 고쳐도 됩니다: `config/watchlist.txt`에 미국은 티커, 한국은 6자리 코드(코스닥은 `247540:KQ`).

## 노트 종목 넣기

`config/notes/<티커>.json`에 적정주가 노트의 종목 문서를 넣으면 노트 탭에 나타납니다. Claude 채팅에서 「노트 종목을 앱 저장소에 반영해줘」라고 하면 같은 형식으로 넣어 줍니다. 가정(성장률·이익률·WACC 등)은 손대지 않고, 매일 시세·200일선·목표주가·Forward EPS만 갱신합니다. 저장된 실적 발표일이 지나면 「실적 반영 필요」 표시가 붙습니다.

## 계산 방식

| 항목 | 내용 |
|---|---|
| 상대가치 | Forward EPS × 같은 시장·업종 Forward PER 중간값 (3개사 미만이면 업종 → 섹터 순으로 넓힘). 적자면 주당 예상매출 × PSR |
| DCF | 5년 FCFF + 영구가치, WACC는 CAPM(미국 10년 국채는 매일 ^TNX로 갱신) |
| 종합 | DCF 50 : 상대가치 50, 업종별 오차범위(±5~25%) |
| 1차 선별 | 영업이익·FCF 흑자, 순부채/EBITDA ≤ 3배, EBIT/EV ≥ 8% 또는 FCF 수익률 ≥ 6% 또는 Forward PER ≤ 업종 × 0.75 |
| 2차 | 괴리율 ≤ −15%이고 DCF·상대가치 모두 현재가보다 높으면 후보, 하나만 높으면 관찰 |
| 자동 보정 | 베타 0.5 미만 조정, 얇은 이익률 시나리오 폭 축소, 업황 고점(이익률 > 5년 평균 × 1.5)이면 5년 뒤 이익률을 평균으로 |
| 함정 점검 | 200일선 아래, 애널리스트 5명 미만, 영구가치 85% 초과, 내년 EPS 감소, 영업외 이익 과다, 매출 컨센서스 없음, 금융 자회사 부채 등 |

금융업(은행·보험·리츠)은 이 방식에 맞지 않아 제외합니다. 일회성 손익, 리스 부채, 지배구조 같은 판단은 자동으로 하지 않으니, 후보가 나오면 Claude 채팅에서 「티커 적정주가」로 다시 확인하세요.

## 폴더 구조

```
app/                화면 (index.html, sw.js, manifest, icons). app/data/는 실행 때 생성
pipeline/
  universe.py       감시 종목 목록 (S&P 500 위키백과, KRX 시가총액 상위, 실패 시 고정 목록)
  fetch.py          yfinance 시세·재무·컨센서스
  run.py            매일 실행: 시세는 전 종목, 재무는 5일에 한 바퀴
  build.js          업종 중간값 → 선별 → 적정가 → app/data/*.json
  engine.js         적정가 계산 엔진 (적정주가 노트와 같은 코드)
  screen.js         선별·문서 규칙 (적정주가 노트와 같은 코드)
  add_watch.py      이슈 제목으로 감시 종목 추가
config/             params.json(금리·위험프리미엄), watchlist.txt, notes/
fixtures/           네트워크 없이 시험하는 데이터
tools/make_icons.py 아이콘 다시 만들기
```

## 내 컴퓨터에서 시험

```bash
python3 pipeline/run.py --fixture fixtures --today 2026-10-19
node pipeline/build.js 2026-10-19
cd app && python3 -m http.server 8000   # http://localhost:8000
```

실제 데이터로 돌리려면 `pip install -r pipeline/requirements.txt` 후 `python3 pipeline/run.py --full`.

## 알아둘 점

- **Yahoo 요청 제한**: yfinance는 공식 API가 아니라서, GitHub 서버에서 많이 요청하면 일시적으로 막힐 수 있습니다. 연속 25회 실패하면 그날 재무 갱신을 멈추고 시세만 반영합니다. 다음 날 이어서 받습니다.
- **한국 종목 목록**: 한국거래소 정보데이터시스템 조회가 막히면 고정 목록(대형주 30개)으로 대신합니다. 정보 탭의 데이터 항목이나 Actions 기록에서 확인할 수 있습니다.
- **예약 실행 중지**: GitHub는 활동이 없는 공개 저장소의 예약 실행을 60일 뒤 멈출 수 있습니다. 멈추면 Actions 탭에서 다시 켜면 됩니다.
- **금리·위험프리미엄**: 미국 10년 국채만 자동입니다. 국고채 10년, 주식위험프리미엄은 `config/params.json`을 가끔 손으로 고칩니다.
- **공개 저장소**: 계산 결과와 관심 종목 목록이 공개됩니다. 보유 수량·계좌·API 키는 절대 넣지 마세요.
